Alcance: app Android (Java), backend Spring Boot 3.5 en Google Cloud Run y PostgreSQL en Neon.

1. Resumen

Se evaluó Abarrato con ISO/IEC 25010:2023 (calidad del producto), ISO/IEC 27001/27002:2022 (codificación segura y perfiles de acceso) y las listas OWASP vigentes: Top 10:2025, API Security Top 10:2023 y Mobile Top 10:2024. Se agregaron pruebas de caja negra, blanca y gris, perfiles de base de datos y cinco correcciones de seguridad.

La aplicación cumple 7 de las 9 características de calidad y cumple parcialmente las otras 2. No quedan hallazgos de seguridad de severidad alta en el código; los pendientes de prioridad alta son de configuración: suspender el backend antiguo y aplicar los perfiles en Neon.
